# Iwade Kitan / 岩出奇譚

Japanese mystery visual novel (work in progress).

- Original story and script: Sin Bach Sirokuma
- Music: Sirokuma
- Episode 1: 関ノ音 / Chapter 1: コピー紙を切る女

## Current status
The Chapter 1 playable package is being prepared for repository upload. The existing HTML, backgrounds, transparent character sprites and audio are not yet deployed here. Do not mistake this README-only repository for a playable build.

## Game file layout
```
index.html
assets/bg/
assets/sprites/
assets/audio/
```

Keep all paths and filenames in ASCII. When the project is uploaded, open `index.html` or deploy the folder as a static website.

## Audio notice
Browser autoplay of unmuted music can be blocked until a user interacts with the page. Title music should attempt autoplay; the existing "はじめる" interaction enables audio when needed.

All game artwork, soundtrack and scenarios are work in progress; rights reserved by the creator.
